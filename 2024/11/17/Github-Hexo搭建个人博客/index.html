Github+Hexo搭建个人博客

发表于 2024-11-17 分类于 实战

搭建原理

想要搭建一个博客网站，首先你需要有一个服务器，然后在服务器上部署前端页面

而Github的github.io就相当于一个免费的服务器，并且可以自动部署你上传的前端页面

而Hexo是一个快速、简洁且高效的博客框架，它最主要的功能就是基于你的Markdown文档，生成静态网页，即前端页面

所以，只要你手持Github + Hexo，就可以把你的Markdown文档转换成静态页面，再通过github自动部署成你的个人博客

Hexo拥有很多的主题，主题可以理解为博客的皮肤，不同的主题能够生成不同风格和功能的静态页面

WSL安装

如果你使用Linux服务器，你可以跳过这一步，如果你使用windows，推荐你使用WSL，即Windows Subsystem for Linux

首先你得有Windows Power Shell，然后通过微软应用商店安装ubuntu22.04，以下是几个安装的踩坑点：

  • 关闭代理，再打开微软应用商店
  • 登陆微软账号，再点击获取Ubuntu
  • 开启代理，再点击应用列表，找到获取的Ubuntu，点击安装
